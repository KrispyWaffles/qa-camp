# BUG-007 — invalid email format accepted

**Environment:** macOS | Chrome | FoxAuth v1.0 (local)
**Severity:** Critical / Major / Minor / Trivial
**Priority:** High / Medium / Low

## Steps to reproduce
1. Open FoxAuth login form
2. write a word without "@" (hello was used)
3. password doesn't effect output

## Expected result
Message "Please enter valid email"

## Actual result
Message "No account found with the email"

## Notes
Security issue - Bad actors and batch experiment emails and find emails that have an account.
