# BUG-008 — password logged into console

**Environment:** macOS | Chrome | FoxAuth v1.0 (local)
**Severity:** Critical 
**Priority:** High 
## Steps to reproduce
1. Open FoxAuth login form
2. right click, open inspect tool
4. Enter correct email (tester@foxreply.com)
5. Enter correct password (Test1234!)

## Expected result
Password character encrpyted or no output in console

## Actual result
Password is being output in console

## Notes
Security issue - Bad actor can easily obtain password information, especially is work station or machine left unattended and unlocked
