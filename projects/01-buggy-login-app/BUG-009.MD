# BUG-009 — Show/Hide Label Reversed

**Environment:** macOS | Chrome | FoxAuth v1.0 (local)
**Severity:** Critical / Major / Minor / Trivial
**Priority:** High / Medium / Low

## Steps to reproduce
1. Open FoxAuth login form
2. enter a password
3. click the Show/Hide text (button) and the end of the opt-in bar

## Expected result
Show / Hide should accurately correspond password. Hide = password hidden / Show = password revealed

## Actual result

The state of Show/Hide don't match whats being displayed. Show = password hidden / Hide = password revealed


## Notes
Low/Medium impact. This can defintely expose sensitive info to Bad Actors if their in proximity.
