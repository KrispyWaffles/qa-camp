# BUG-001 — success message exposes password

**Environment:** macOS | Chrome | FoxAuth v1.0 (local)
**Severity:** Critical 
**Priority:** High

## Steps to reproduce
1. Open FoxAuth login form
2. Enter correct email (tester@foxreply.com)
3. Enter correct password (Test1234!)

## Expected result
Success login message

## Actual result
Success login message is displaying password in plain text in the UI after log in

## Notes
Security issue - Bad actors can look over the shoulder or being a good enough proximity to see the login credintals.
