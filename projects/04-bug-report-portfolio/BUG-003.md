# BUG-003 — user enumeration (different errors for wrong email vs wrong password)

**Environment:** macOS | Chrome | FoxAuth v1.0 (local)
**Severity:** Critical 
**Priority:** High 

## Steps to reproduce
1. Open FoxAuth login form
2. Enter incorrect email
3. password doesn't effect output

## Expected result
Correct message - Please enter valid email"

## Actual result
"No account found with that email"

## Notes
Security issue - Bad actors and batch experiment emails and find emails that have an account.
